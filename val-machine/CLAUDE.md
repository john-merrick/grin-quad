## Agent skills

### Issue tracker

Issues tracked in GitHub Issues (`github.com/john-merrick/val-machine`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.
Any mistakes in MISTAKES.md (what happened, root cause, prevention)

### Triage labels

Default label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
